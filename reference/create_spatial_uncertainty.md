# Create Spatial Uncertainty instance

Convenience function to create a SpatialUncertainty instance with
default configuration.

## Usage

``` r
create_spatial_uncertainty(...)
```

## Arguments

- ...:

  Additional configuration parameters

## Value

SpatialUncertainty instance

## Examples

``` r
if (FALSE) { # \dontrun{
uncertainty <- create_spatial_uncertainty()
} # }
```
