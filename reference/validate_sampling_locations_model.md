# Validate sampling locations data structure

Validate sampling locations data structure

## Usage

``` r
validate_sampling_locations_model(
  sampling_locations,
  field_data = NULL,
  strict_validation = TRUE
)
```

## Arguments

- sampling_locations:

  Data frame with sampling locations

- field_data:

  Optional field data for boundary validation

- strict_validation:

  Logical for strict constitutional compliance

## Value

List with validation results
