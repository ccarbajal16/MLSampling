# Validate spatial consistency across uncertainty components

Validate spatial consistency across uncertainty components

## Usage

``` r
validate_spatial_consistency(epistemic, aleatoric, total, field_data)
```

## Arguments

- epistemic:

  Epistemic uncertainty

- aleatoric:

  Aleatoric uncertainty

- total:

  Total uncertainty

- field_data:

  Reference field data

## Value

List with spatial consistency results
