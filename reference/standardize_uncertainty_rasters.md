# Standardize uncertainty rasters

Standardize uncertainty rasters

## Usage

``` r
standardize_uncertainty_rasters(
  uncertainty_rasters,
  epistemic,
  aleatoric,
  total
)
```

## Arguments

- uncertainty_rasters:

  Raw uncertainty rasters

- epistemic:

  Epistemic uncertainty for reference

- aleatoric:

  Aleatoric uncertainty for reference

- total:

  Total uncertainty for reference

## Value

Standardized uncertainty rasters list
